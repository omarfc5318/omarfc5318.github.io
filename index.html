Statistical Arbitrage Engine

Pairs Trading · S&P 500 ETFs · Sharpe 2.01

Overview

A systematic pairs trading strategy built on cointegration testing and Kalman Filter dynamic hedge ratio estimation. Applied to S&P 500 sector ETFs with HMM regime switching to avoid trading in unfavorable market conditions. Achieved a Sharpe ratio of 2.01 in backtesting.

Methodology

Engle-Granger cointegration tests for pair selection · Kalman Filter for time-varying hedge ratios · Fama-French 3-factor alpha attribution · Regime-conditioned position sizing · Streamlit interactive backtest dashboard.

ContractForge

NLP → Smart Contract · ResilientDB Deployment

Overview

A full-stack chatbot that generates and deploys Solidity smart contracts from plain-English descriptions. Integrated with ResilientDB's blockchain infrastructure at UC Davis ExpoLab. Uses the DeepSeek API with few-shot learning for high-quality contract generation.

How It Works

User describes their contract in natural language → Few-shot prompting selects the best template → DeepSeek generates Solidity → Contract is validated, compiled, and deployed to ResilientDB. Full-stack interface built for non-technical users.

NBA Injury Prediction

AUC 0.956 · 88% Accuracy · 11K+ Records

Overview

A machine learning system that predicts NBA player injuries using historical game logs, workload trends, and biometric data. Trained on 11,000+ player-season records with class imbalance handled via SMOTE oversampling.

Results

XGBoost ensemble achieved AUC of 0.956 and 88% accuracy on holdout data. Random Forest baseline for comparison. Engineered features include rolling fatigue scores, back-to-back game flags, and positional stress metrics.

L-Store Database System

Columnar Storage · Buffer Pool · Query Engine

Steam Game Review Analysis

What makes a game well-reviewed? · Top 1000 Steam games

Overview

An end-to-end data pipeline and analysis project exploring the factors that drive positive Steam reviews. Scraped 1,000+ games using the Steam API and SteamSpy, built a relational SQLite database, and performed sentiment analysis on user reviews.

Key Findings

Playtime distribution, price point, and developer response rate were among the strongest predictors of positive review ratios. NLP sentiment scores correlated strongly with overall rating despite being derived independently.
